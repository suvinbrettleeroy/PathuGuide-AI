🎓 College Project — Flask · Bilingual · EN / TA

Career & Government Exam
Guidance, Made Personal

PathGuide helps students in Tamil Nadu plan a career path or prepare for government exams — with personalized roadmaps, a bilingual interface, and an admin dashboard to manage it all.

View Source on GitHub Run It Locally
What it does

Two guided paths, one platform

Students choose their track from the dashboard, fill a short form, and get a roadmap built around their answers.

🧭

Career Path Guidance

Degree → Department → Domain → Role mapping with a generated study plan, salary outlook, and course/project suggestions.

🏛️

TN Government Exam Prep

Exam–job mapping, syllabus breakdown, a study roadmap by timeline, and a physical fitness eligibility checker.

🌐

Bilingual Interface

Every page toggles between English and Tamil, including forms and generated output.

🔐

Admin Dashboard

A separate, protected panel for the team to manage content, with its own light/dark theme.

📍

Live Location Detection

Detects the student's location to tailor recommendations and coaching center suggestions.

🎨

Custom Design System

A hand-built visual identity — brand logo, motion, and a shared component library across every page.

Visual identity

Designed around the journey

Imagery used across the app's pages, echoing the climb from student to career.

Try it yourself

Run it locally

Since GitHub Pages can't run a Python server, clone the repo and run PathGuide on your own machine:

$ git clone https://github.com/suvinbrettleeroy/PathuGuide-AI.git $ cd PathuGuide-AI/Code $ python -m venv venv && venv\Scripts\activate $ pip install -r requirements.txt $ python app.py # then open http://127.0.0.1:5000
